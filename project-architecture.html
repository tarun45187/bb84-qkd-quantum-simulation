Theoretical Foundations & Mathematical Rigor

Complete derivations of Bennett-Brassard 1984 (BB84), Shor-Preskill security proofs, Holevo bounds, CNOT ancilla probes, and NIST FIPS 203 (ML-KEM) lattice cryptography.

1. Quantum State Spaces & Mutually Unbiased Bases (MUBs)

BB84 operates on two-dimensional Hilbert space \(\mathcal{H}_2\). Alice encodes classical bits into two conjugate, non-orthogonal bases:

Computational / Rectilinear (Z): {|0⟩, |1⟩} with angles θ = 0°, 90°
Hadamard / Diagonal (X): {|+⟩, |−⟩} where |±⟩ = (|0⟩ ± |1⟩) / √2

These bases are mutually unbiased because the overlap between any state in \(\mathcal{B}_Z\) and any state in \(\mathcal{B}_X\) is strictly constant:

|⟨z_i | x_j⟩|² = |(1 / √2)|² = 1/2 = 50%

By Heisenberg's Uncertainty Principle and the No-Cloning Theorem, any measurement by an eavesdropper in the incorrect basis irrevocably collapses the quantum superposition, introducing detectable disturbance.

2. The Shor-Preskill Security Proof & 11% Abort Threshold

In 2000, Peter Shor and John Preskill proved the unconditional security of BB84 by reducing it to Calderbank-Shor-Steane (CSS) quantum error-correcting codes.

Asymptotic Secret Key Fraction: R ≥ 1 - 2 · H₂(QBER)

Here, \(H_2(p)\) is the binary Shannon entropy function:

H₂(p) = -p · log₂(p) - (1 - p) · log₂(1 - p)
Step 1: To correct bit-flip errors (\(X\)), Alice and Bob sacrifice fraction \(H_2(QBER)\) of sifted bits via classical error correction.
Step 2: To correct phase-flip errors (\(Z\)), which represent Eve's entanglement with the quantum channel, they sacrifice another fraction \(H_2(QBER)\) via privacy amplification.
Step 3: The protocol yields positive distilled key length only if \(R > 0\), which requires:
1 - 2 · H₂(QBER) > 0 ⟹ H₂(QBER) < 0.5000 ⟹ QBER < 11.00%

If the measured sample QBER exceeds 11.0%, Alice and Bob must immediately abort the protocol, as Eve may possess complete knowledge of the distilled key.

3. Ancilla Probe Attack & Mutual Information Advantage

Eve couples an ancilla qubit \(|0\rangle_E\) to Alice's photon using a controlled unitary operation (such as a CNOT gate):

U_CNOT |0⟩_A |0⟩_E = |0⟩_A |0⟩_E
U_CNOT |1⟩_A |0⟩_E = |1⟩_A |1⟩_E
U_CNOT |+⟩_A |0⟩_E = (|00⟩ + |11⟩) / √2 = (|+⟩|+⟩ + |−⟩|−⟩) / √2

By the Csiszár-Körner theorem, secret key distillation via one-way classical public communication is possible if and only if Alice and Bob share a mutual information advantage over Eve:

ΔI = I(A; B) - I(A; E) > 0

In an Intercept-Resend attack where Eve intercepts 100% of photons, the induced QBER is 25%. At this point, \(I(A; B) = 1 - H_2(0.25) \approx 0.1887\), while Eve's mutual information \(I(A; E) \approx 0.5000\), resulting in \(\Delta I < 0\) (fatal information deficit).

4. Privacy Amplification via Universal₂ Toeplitz Hashing

After Cascade error correction, Alice and Bob share an identical raw key \(K_{corrected}\) of length \(n\), but Eve may possess partial parity information disclosed during public reconciliation.

To distill a completely secret key of length \(m\), they use a random Toeplitz matrix \(T \in \{0, 1\}^{m \times n}\) where matrix elements along each diagonal are constant: \(T_{i, j} = a_{i - j}\).

K_final = (T · K_corrected) mod 2

Toeplitz hashing forms a Universal\(_2\) hash family, ensuring that Eve's Renyi collision entropy is maximized and her expected information on the distilled key is exponentially bounded by \(2^{-s}\), where \(s\) is the security parameter.

5. NIST PQC: Module Learning With Errors (ML-KEM / Kyber)

NIST FIPS 203 standardized ML-KEM (based on CRYSTALS-Kyber) as the primary global post-quantum key encapsulation mechanism.

M-LWE Problem: Given (A, b = A·s + e) over polynomial ring R_q = ℤ_q[X]/(X²⁵⁶ + 1),
find secret vector s ∈ R_q^k given small error vector e ∈ R_q^k.

Comparison Summary:
• BB84 QKD provides information-theoretic security grounded in the laws of quantum mechanics, but requires dedicated optical fibers, single-photon detectors, and trusted repeater nodes.
• ML-KEM provides computational security based on the worst-case hardness of module lattice problems, running seamlessly on ordinary microprocessors across the open global internet.
